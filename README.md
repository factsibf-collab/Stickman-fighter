# Red Moon: Stickman Fighters

A 2D stickman fighting game designed for Android.

## Features

- Blood Moon fighting arena
- Player versus AI combat
- Punch and kick attacks
- Health bars
- Five planned AI difficulty levels
- Coins and rewards
- Gloves, shoes and weapons planned
- Android APK support through Godot

## Development

Game Engine: Godot  
Language: GDScript  
Platform: Android

## Current Version

Early prototype.

The project will be expanded with a proper
shop, equipment inventory, animations,
difficulty selection and additional combat systems.
